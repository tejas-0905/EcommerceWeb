# 🛒 Ecommerce MERN Project

A **full-stack Ecommerce Web Application** built using the **MERN stack** (MongoDB, Express, React, Node.js) with an **Admin Panel** to manage products, orders, and users.

---

## 📌 Tech Stack

- Node.js  
- Express.js  
- React  
- MongoDB  
- JavaScript  
- VS Code  

# 🚀 How To Run Project

This guide explains how to **set up and run the full project** — including both **Backend** and **Frontend/Admin Panel** — on your local machine.

---

## ⚙️ Step 1: Install Node.js

> **Skip this step if Node.js is already installed.**

1. Visit the official Node.js website:  
   👉 [https://nodejs.org/en/download/](https://nodejs.org/en/download/)
2. Download the installer for your operating system.
3. Run the installer.
4. Follow the prompts to complete the installation.

---

## 🧩 Step 2: Setup Backend of the Project
